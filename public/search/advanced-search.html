Tips for better results

  • Rows Add rows to expand your search, or delete rows to simplify it.
  • Search fields Search a specific field (Title, Creator, Subject, Description) instead of everywhere.
  • Match type Each row can require its terms (Contains all), allow either (Contains any), or exclude them (Does not contain).
  • Filters Narrow by object type, collection, creator, licence, access and production date — each filter has its own Includes all (AND) / Includes any (OR) choice.
  • Exact phrase Use quotation marks to search for an exact phrase, e.g. "eucalyptus oil".

Search examples

  • All Fields → Contains all eucalyptus oil bottle will display records with all three terms anywhere in the record.
  • Subject → Contains all botanical illustration will display records with botanical AND illustration in the subject field.
  • Subject → Contains any botanical illustration will display records with botanical OR illustration in the subject field.

Filter examples

  • Object Type → Includes all Photograph, Manuscript will display records tagged with both Photograph AND Manuscript.
  • Object Type → Includes any Photograph, Manuscript will display records tagged with either Photograph OR Manuscript.
