## Message strings by area
Only en.yml, blacklight.en.yml, pagination.en.yml, search_bar.en.yml and advanced_search.en.yml exist.
- Saved: `blacklight.bookmarks.*`, `nexus_ccs.save.*` (Save, Saved, Saving...), `nexus_ccs.saved_noun`, `nexus_ccs.saved.list_description`.
- Search: view names "List view" / "Mosaic view"; sorts relevance, date (newest), date (oldest), title (A-Z), title (Z-A); "%{count} results per page"; range "From" / "To".
- Pagination: Previous, Next, "Previous page", "Next page".
- In code, not yml: `QueryRules::INVALID_MESSAGE`, `REMOVED_MESSAGE`, unavailable page copy, zero-results hint and button, spelling copy.

## Rails vs Static
Error pages (Rails stock without chrome vs none); loading (Rails page loader and skeleton vs inline aria-busy block); backend failure (503 card vs silent fallback); saved storage (guest DB vs localStorage 500); history (session 5 recent vs localStorage 100 for 30 days); query sanitising and flash only Rails; skip link only on some static pages; Country modal Rails only; back to top only where pagination renders in Rails.
