# Advanced Search

Combine fields and filters to find exactly what you're looking for across the collections.

## Search

Tip:

- Narrow the search by selecting the fields to be searched.
- Add rows for more search terms or refine the matches by types.
- Refine the matches by indicating the types of matches required. E.g. Contains all, Contains any, or exclude them.
- Use quotation marks to search for an exact phrase, e.g. "eucalyptus oil".

## Filters

Narrow your results

Tip:

- Select Add filter to choose other filters. You can delete any filter lines you don’t need.
